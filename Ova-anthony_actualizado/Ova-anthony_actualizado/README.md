## Contenido
- `index.html`: OVA completa con estilos y JavaScript integrados.
- `ficha_tecnica.pdf`: ficha técnica del proyecto.

## Ejecutar localmente
Abre `index.html` en un navegador moderno. No requiere instalación ni conexión a internet para sus interacciones.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `README.md` y `ficha_tecnica.pdf`.
3. En Settings → Pages, selecciona Deploy from a branch, rama `main`, carpeta `/root`.
4. Guarda y espera el enlace público.

También puedes arrastrar la carpeta a Netlify Drop o desplegarla en Vercel como sitio estático.

## Tecnologías
HTML5, CSS3 y JavaScript nativo. Diseño adaptable a móviles y escritorio.
